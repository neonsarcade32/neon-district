Next steps to make it live

01 · Deploy the engine

Use a server you control and verify its startup instructions, license, dependencies, and security settings. The public Achroma engine repository currently exposes engine source files but not a ready-to-run package manifest at its root.

02 · Configure access

Use HTTPS and restrict access to your own account or trusted users. Do not publish an unrestricted open proxy; it can be abused and may expose your server.

03 · Connect and test

Enter the deployed frontend URL above. This page checks basic reachability; a successful check alone does not prove every website or proxy route works.

04 · Test on iPad

Confirm a site loads, navigation works, and the server does not expose credentials or private browsing data before relying on it.
