FREE-QUOTA SETUP · NO APP INSTALL

MAKE YOUR OWN BROWSER 🚀

Follow these steps once to get a private remote Chromium browser. You don't need to know coding — copy one command, then open your personal link.

START ON GITHUB ↗
01

Get your GitHub account

Sign up free or sign in to your own account. This account owns your cloud computer — nobody needs the Neon District creator's login.

GitHub account eligibility and terms apply. If you already have an account, skip this step.

02

Create your Codespace

Open the Neon District GitHub repository. Tap Code → Codespaces → Create codespace on main. Wait for the editor to load.

Check the GitHub message about who pays. Use your own included allowance; don't enable paid usage.

03

Paste one command

In Codespaces, open Terminal. Paste this command, then press Enter. The first run downloads Chromium, so it may take a few minutes.

This starts a real Chromium browser in your own Codespace — not in Neon District's public site.

bash browser-lab/start.sh

Tap COPY, then paste it into GitHub's terminal.

04

Open YOUR browser link

In the bottom panel, tap Ports. Find 3200 (or choose Forward a Port and enter 3200). Keep visibility Private, then tap the globe/open icon.

Your own Chromium should open in Safari. TikTok is set as the starting website, but playback and sound aren't guaranteed.

05

Stop it when you're finished

In Codespaces Terminal, run docker stop nd-personal-browser to stop Chromium. Then visit Your Codespaces and stop your Codespace to avoid using more cloud hours.

Closing the Safari tab alone doesn't necessarily stop your Codespace.

🔐Important: Every visitor must use their own GitHub account and Codespace. Neon District only provides instructions and a starter script; GitHub runs each person's cloud computer. Keep port 3200 Private and never share that forwarded link. Free Codespaces time and storage are limited, so check your GitHub usage before starting.

Questions? We got you.

💸 Is it actually free?

GitHub Free personal accounts include a limited monthly Codespaces allowance. Using those included hours can cost $0, but it's not unlimited. If GitHub asks you to add billing or enable paid usage, you can stop instead. Check usage in your GitHub account.

👥 Can my friend and I use it at the same time?

Yes — if you're each eligible for Codespaces and you each start a Codespace on your own GitHub account. You won't control the same browser or use the Neon District creator's session.

🌐 Is this directly inside the Neon District website?

Not yet. The free setup opens your private streamed Chromium in a separate GitHub Codespaces link. The regular Neon Browser launcher above opens websites in Safari. An embedded one-click cloud browser for everyone would require additional hosting.

🎵 Does TikTok, scrolling, video, and audio work?

The starter launches real Chromium with TikTok as the home page. Touch, video, audio, and access to individual websites depend on GitHub cloud performance, Safari, and each website. They may lag, be muted, or be restricted.

🛠️ What if I get a white screen or “Connecting…”?

Give Chromium a minute to start, then reload the private port 3200 tab. In Codespaces Terminal, run docker ps --filter name=nd-personal-browser to see if it is running. If needed, check docker logs --tail 30 nd-personal-browser. Don't switch the port to Public to fix loading issues.

📴 Does closing Safari stop the browser?

No. Stop your Codespace from your GitHub account to avoid spending more free minutes. For the Chromium container alone, use docker stop nd-personal-browser.

FULL CLOUD BROWSER FOR EVERYONE

Why it isn't live yet

NOT DEPLOYED

A one-click, fully interactive remote browser for every visitor can't realistically be supported by GitHub Pages or unlimited free cloud computing. Each live Chromium browser consumes CPU and memory; a shared remote desktop would expose other visitors' sessions. We're preserving the free launcher and optional personal setup while keeping this larger goal on the roadmap.
