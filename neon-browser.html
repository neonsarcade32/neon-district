FULL CLOUD BROWSER FOR EVERYONE

Why it isn't live yet

NOT DEPLOYED

A one-click, fully interactive remote browser for every visitor can't realistically be supported by GitHub Pages or unlimited free cloud computing. Each live Chromium browser consumes CPU and memory; a shared remote desktop would expose other visitors' sessions. We're preserving the free launcher and optional personal setup while keeping this larger goal on the roadmap.
